# 文化社会学 · Cultural Sociology

> 一个分三条路线的文化社会学工作台：先问你走哪条路，再给概念、方法、写作骨架与评审量表。

文化社会学的门槛不在"读没读过布迪厄"，而在**路线判断**：同一个现象，走布迪厄路线问的是"谁得到了什么、为什么能代代相传"，走强纲领路线问的是"这件事为什么被理解成这样"，走计算测量路线问的是"这种理解有多广、怎么变"。三条路线对"意义在哪里""文化是不是原因""什么算证据"给出**互不相容**的答案。选错路线，论文从第一段就歪了。

这个技能把这件事变成一道可以回答的选择题，然后把七类任务接到各自的工序上。

## 三条路线

| | 布迪厄路线 | 强纲领路线 | 计算测量路线 |
|---|---|---|---|
| 文化是什么 | 被争夺、可兑换的权力资源 | 自足的意义结构，有自身语法与因果力 | 可测量、可比较的意义分布 |
| 关键概念 | 惯习、场域、资本、象征暴力、区隔、边界 | 二元符码、叙事文类、文化创伤、公民领域、社会表演 | 意义结构、主题、语义维度、关系构型 |
| 典型方法 | 对应分析、场域民族志、生活史访谈 | 厚描、档案与文本编码、过程追踪 | 主题模型、词嵌入、网络与关联规则 |
| 贡献 | 揭穿一个看不见的再生产机制 | 造一个可被别人拿去用的概念 | 给一套可复用的测量 |
| 软肋 | 变迁与能动性 | 可证伪性 | 效度与语境 |

计算测量路线另附**计算社会学补编**：本体论（文化是哪一类东西）→ 解释的测量（归类 P(c|s) + 联想 P(a|c)）→ 人机分工（三种"计算扎根"）→ 因果与预测的边界。

## 它覆盖七种场景

| 场景 | 用户说的话 | 交付物 |
|---|---|---|
| 科普解释 | "文化社会学是什么""什么是象征暴力" | 定义 → 对照 → 例子 → 边界 |
| 现象解读 | "用文化社会学解释小镇做题家" | 定客体 → 选路线 → 找结构 → 排过程 → 给反例 |
| 专业答疑 | "惯习和习惯有什么区别""场域是不是就是行业" | 定义 → 出处 → 它反对什么 → 误用 → 另一路线怎么看 |
| 系统学习 | "带我学文化社会学" | 三条并行的四周路径 + 自测题 |
| 选题设计 | "我想研究彩礼，从哪切入" | 3–5 个候选 + 六维评估矩阵 + 选题卡 |
| 论文写作 | "帮我写理论框架""引言怎么写" | COPE-R / 场域分析 / 测量论文三套骨架 + 篇幅分配 + 句式 |
| 质量评估 | "这篇论文怎么样" | 先判路线，再按分路线权重打 100 分 + 三段评语 + 提升路径 |

## 依据

- 素材：**106 份 PDF / 12,682 页 / 3,006 万字符**（文化社会学 98 份：布迪厄 16、强纲领 49、计算测量 22、拉蒙 8、后殖民 3；计算社会学 8 份）。
- 精读：按字符加权 **约 32.7%**，逐份比例与阅读范围见 `references/audit.md`。**没有声称通读全文**——1200 页以上的专著是选读关键章。
- 页码一律为 PDF 物理页，用于定位，不替代原文核对。
- 已修正若干流传较广的错误说法（强纲领是三条不是四条；Mohr 2020 无"四条路径"；*Making Sense of Culture* 是 Patterson 2014；Vaisey 2009 未用 MODE；Edelmann 等 2020 是"解释/预测"二分而非四分法），逐条见 `audit.md` §3。

## 使用

把整个目录放进 WorkBuddy 的技能目录（`~/.workbuddy/skills/cultural-sociology/`），或在支持 Agent Skills 的客户端中加载 `SKILL.md`。也可直接阅读 `references/` 下的文件——它们本身是可独立使用的知识底稿。
